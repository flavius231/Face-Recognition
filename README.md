# Face-Recognition
## Setup:
1. **Create venv:** `python3 -m venv .venv`
2. **Activate venv:**
   - **Windows (powershell):** `.venv/Scripts/Activate.ps1` (if prompted with an error use: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)

   - **Windows (cmd):** `.venv\Scripts\activate.bat`
   
   - **Linux:** `source .venv/bin/activate`
3. Install python modules: `pip install -r requirements.txt`
